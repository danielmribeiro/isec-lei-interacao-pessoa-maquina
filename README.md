## Course Objectives

The main objective of this course is to introduce students to the fundamental principles and rules for designing and developing user interfaces that are usable, useful, efficient, and safe.
The student will develop the following essential skills:

* Identify users and the tasks they aim to perform with the interactive system.
* Evaluate interfaces at different development stages using appropriate evaluation techniques.
* Identify critical factors in interface design.
* Understand and manage trade-offs between constraints in interface design.
* Frame interface design within software engineering projects.
